# Changelog

## v1.0.0 — 2026-10-05

- Initial public release of the Thai localization mod.
- Added Thai localization for menus, UI, dialogue, items, documents, journal entries, puzzle text, New Game+, and supported ending/credits text.
- Added Thai language selection to the in-game language menu.
- Added selectable Pixel and Smooth Thai font modes.
- Added Thai-specific layout and rendering fixes for documents, journals, popups, result screens, special interfaces, and ending scenes.
- Completed a full manual playthrough and multiple focused QA passes for translation, typography, routing, and layout.
- Disabled development diagnostics and test UI by default for normal players.
